カーネル開発プロセスの手引
==========================

この文書の目的は、開発者（とその管理者）が、開発コミュニティーと共に
作業する際に感じるかもしれない不満を低減することです。
Linux カーネル開発（もしくは一般にフリーソフト開発）にあまり馴染みのない
人々にもわかりやすい形で、このコミュニティーがどのように機能するかを
文書化する試みです。
ある程度技術的な内容も含みますが、カーネルプログラミングについての
深い知識なしに理解できる、手続き（訳註: process）を対象とする議論です。
